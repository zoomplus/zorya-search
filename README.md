# Zorya Search

`@zorya/search` — SDK и MCP-сервис поиска по разрешённым репозиториям и внешним источникам. Его вызывает существующее приложение или агент, который сам выбирает, когда искать и как проверить результат. Search возвращает источники и кандидаты; он не меняет код, prompt, модель, память или настройки клиента.

## Быстрый старт

Требуется Node.js `>=20.19.0`.

После публикации пакета эти команды запускают поиск из каталога нужного репозитория. Ключи им не требуются, пока поиск остаётся лексическим.

```sh
npx --yes @zorya/search setup --root "$PWD"
npx --yes @zorya/search index
npx --yes @zorya/search search --query "где обрабатывается запрос"
npx --yes @zorya/search client-config
```

Пакет пока не опубликован. Сейчас можно установить полученный от сопровождающего файл `.tgz` только в текущий проект, без глобальной установки. Укажите путь к локальному файлу архива.

```sh
SEARCH_TARBALL=/path/to/zorya-search-0.1.0.tgz
npm install --no-save --no-package-lock "$SEARCH_TARBALL"
./node_modules/.bin/zorya-search setup --root "$PWD"
./node_modules/.bin/zorya-search index
./node_modules/.bin/zorya-search search --query "где обрабатывается запрос"
./node_modules/.bin/zorya-search client-config
```

По умолчанию поиск работает по словам и не обращается к моделям. Если владелец разрешил отправлять код внешнему сервису, задайте ключ в окружении процесса и при настройке передайте только имя переменной, например `--code-env OPENROUTER_API_KEY`. Встроенный code preset использует `voyageai/voyage-code-4` размерности 1024 и `voyageai/rerank-2.5-lite` для shortlist до 30 кандидатов с возвратом до 8. Визуальный поиск использует отдельный профиль `voyageai/voyage-multimodal-3.5` размерности 1024 и включается только при явном выборе через `--visual-env OPENROUTER_API_KEY`. Профили можно включить одной командой настройки; visual ищет только среди изображений, которые клиент сам выбрал и передал. Не передавайте ключ в аргументах команды, URL, prompt или журнале. Настройка профиля не доказывает доступность модели и не означает, что Search уже отправил данные.

Для работы с исходниками пакета клонируйте репозиторий, выполните `pnpm install --frozen-lockfile`, затем `pnpm build`. Пример SDK с `mode: 'lexical'` и перечень доступных входов находятся в [справочнике SDK](docs/sdk.md). Лексический поиск не требует сетевого ключа.

Для MCP используйте отдельное руководство по [локальному daemon и MCP-клиентам](docs/mcp.md). Сначала выберите репозитории, которые владелец сервиса разрешил индексировать. Подключение выполняется явно в настройках выбранного клиента. Установка пакета не подключает инструмент к текущему чату. Локальный SDK/MCP runtime и настроенный клиент — отдельные компоненты.

Dense code retrieval, rerank, web retrieval и visual retrieval настраиваются независимо. Без embedding профиля оставайтесь в lexical режиме. Для отправки кода, текста или изображения внешнему provider требуется осознанная настройка соответствующего клиента; ключи храните в защищённом окружении, не в аргументах процесса, URL, prompt или логах. Visual поиск выключен по умолчанию и работает только с переданными клиентом references. Он не делает desktop capture.

## Текущий статус — 2026-11-01

Исходники доступны в [публичном репозитории GitHub](https://github.com/zoomplus/zorya-search), а npm-пакет пока не опубликован. На базовом snapshot package gates прошли 206/206 тестов, hosted CI run `41263778259` прошёл 8/8 jobs, а установленный CLI — 11/11 локальных проверок. В следующем [hosted CI run 41266842266](https://github.com/zoomplus/zorya-search/actions/runs/41266842266) семь из восьми jobs прошли; Linux PostgreSQL на Node 24 завершился фатальной ошибкой V8 во время запуска PGlite. Новый `pnpm test:node24` запускает тот же набор через отдельные Node 24 test workers с `--wasm-wrapper-tiering-budget=1000000000`; прежний `--no-wasm-code-gc` не доходил от node:test runner до worker-процессов. Автоматически запущенный CLI daemon получает этот флаг только на Node 24; при foreground `serve` его можно передать явной командой. Это ограниченный workaround, а не подтверждённое исправление V8 или квалификация всех Node 24 runtime. Новая hosted CI квитанция ещё ожидается. Подробности и ограничения приведены в [архитектурном обзоре](docs/architecture.md).

Эти проверки относятся к указанным снимкам и сценариям. Они не оценивают широкую релевантность, не задают latency SLA и не квалифицируют Windows-машину пользователя, Witcher, игру или микрофон. Шестипарный пилот завершён. Native результат пары F inconclusive, общий победитель не определён. Текущий ChatGPT MCP не настроен, полная приёмка остаётся незавершённой. Подробности и ограничения приведены в [архитектурном обзоре](docs/architecture.md) и [руководстве MCP](docs/mcp.md).
