# Целостность индекса

- Сохраняй идентичность источника: repository, worktree, snapshot и content hash. Читай и выдавай фрагменты в контексте указанного snapshot; явно показывай stale при несовпадении.
- Отделяй пространства векторов по provider, model, dimensions, input type и версии chunker. Смена профиля не должна незаметно переиспользовать несовместимый индекс.
- При индексировании публикуй завершённое поколение атомарно после перепроверки корня и поколения. Отмена, удаление, переименование и пропущенное событие watcher требуют корректной сверки; не сообщай старое поколение как актуальное.
- Явный lexical режим не вызывает embedding/rerank-модели. Режим hybrid без модели или с несовместимым профилем/снимком возвращает явную lexical деградацию; текущий код пробрасывает ошибку, если сам вызов embedding/rerank завершается ошибкой, и не обещает автоматический fallback на этот случай.
- Проверяй пути и realpath в границах разрешённого корня; учитывай ignore, размер, бинарные и генерируемые файлы. Эти фильтры снижают риск, но не гарантируют обнаружение всех секретов.
- Не передавай векторные массивы в prompt JSON. Перед отправкой кода облачному провайдеру вызывающий продукт должен иметь понятное раскрытие этой возможности и управляемую конфигурацию.
