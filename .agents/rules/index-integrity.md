# Целостность индекса

- Сохраняй идентичность источника: repository, worktree, snapshot и content hash. Читай и выдавай фрагменты в контексте указанного snapshot; явно показывай stale при несовпадении.
- Отделяй пространства векторов по provider, model, dimensions, input type и версии chunker. Смена профиля не должна незаметно переиспользовать несовместимый индекс.
- При индексировании публикуй завершённое поколение атомарно после перепроверки корня и поколения. Отмена, удаление, переименование и пропущенное событие watcher требуют корректной сверки; не сообщай старое поколение как актуальное.
- Явный lexical режим не вызывает embedding/rerank-модели. Режим hybrid без модели или с несовместимым профилем/снимком возвращает явную lexical деградацию; текущий код пробрасывает ошибку, если сам вызов embedding/rerank завершается ошибкой, и не обещает автоматический fallback на этот случай.
- Проверяй пути и realpath в границах разрешённого корня; учитывай ignore, размер, бинарные и генерируемые файлы. Эти фильтры снижают риск, но не гарантируют обнаружение всех секретов.
- Не передавай векторные массивы в prompt JSON. Перед отправкой кода облачному провайдеру вызывающий продукт должен иметь понятное раскрытие этой возможности и управляемую конфигурацию.
- Empty hits не означают отсутствие реализации, если snapshot устарел, индекс неполон или путь исключён. Сохраняй разницу между пустым результатом, provider error, cancellation, partial/degraded и stale.
- Статический symbol graph — отдельная optional metadata, привязанная к source snapshot и analysis profile. Не смешивай её профиль с embedding profile и не сбрасывай chunks, vectors, imports, query rows или paid embeddings при построении/обновлении symbol metadata. Полное `indexRepository` штатного индекса строит metadata вместе с snapshot; `indexCodeSymbols` предназначен для явного backfill существующего актуального base index, а не для повторения перед каждым чтением. Он требует ту же identity, конфигурацию root/exclusions и analysis limits, не вызывает модели и не меняет source index.
- Symbol reads не индексируют и не исправляют отсутствие metadata. Отличай typed failure при отсутствии/устаревании base source index от analysis state `not_indexed` при существующем snapshot без metadata, `partial` при неполном извлечении и `unavailable` при несовместимом analysis profile. Курсор чтения ограничен snapshot, профилем и фильтрами; отвергай foreign/stale cursor. Проверь source generation и active profile перед публикацией результата.
- Счётчики coverage, усечение и неразрешённые связи — часть результата, а не повод считать пустую выдачу доказательством отсутствия связи. `unresolvedReferenceCount` считает ссылки с `targetKind: 'unresolved'`, а `unresolvedCallCount` — их подмножество для `call`/`construct`; `targetKind: 'external'` отдельно означает внешнюю цель. Даже `complete` означает завершение объявленной поддерживаемой static-analysis области, не полноту dynamic dispatch, dependency injection или runtime bindings. Проверяй статические рёбра и диапазон чтением соответствующего snapshot; вызывающая сторона решает, применим ли кандидат.
- Изменения producer/consumer metadata требуют проверок сохранности прежних vector/profile данных, обновления поколения и cancellation, отсутствия неявного backfill при read, границ курсора и совместимости legacy `CodeIndex` adapters с четырьмя прежними read-портами.
- Профиль Mechanism `voyageai/voyage-code-4` и reranker `voyageai/rerank-2.5-lite` относится только к отдельной проверенной конфигурации клиента. `voyageai/voyage-multimodal-3.5` используется как независимый opt-in visual профиль; не считай его code embedding заменой и не создавай desktop capture.
