# Security policy

Zorya Search reads files from explicitly configured repository roots and may use provider-backed features when an owner enables them. Review the configured roots, client permissions, service exposure, and provider settings before deployment. Never commit API keys or include secrets, private source, or personal data in public reports.

## Reporting a security concern

GitHub Issues are enabled for ordinary, non-sensitive bug reports, but private vulnerability reporting is currently disabled for this repository and no separate confidential reporting channel is configured. Do **not** post vulnerability details, exploit steps, credentials, or affected private data in a public issue. There is currently no private channel listed here for sensitive reports; wait until the repository owner publishes one before sending confidential details.

This repository does not state a response-time or remediation SLA. Security fixes and supported-version policy are determined by maintainers when a report can be received through an appropriate channel.
