# Zorya Search

**Поиск по коду и репозиториям для SDK и MCP-клиентов; code embeddings, семантический поиск и reranking включаются отдельно.**

**[Read in English](README.md)**

Zorya Search помогает существующему приложению или агенту находить код в разрешённом репозитории, проверять текущий исходник за результатом и собирать связанные данные. Подключите SDK из Node.js-сервиса или откройте те же возможности клиенту через MCP. Search возвращает ограниченные результаты с привязкой к исходнику; вызывающая сторона решает, когда искать, чему доверять и что делать дальше.

Например, можно найти обработчик триггера инициативы, проверить вызывающие места и тесты для известного символа или получить кандидатов на повторяющиеся тела функций для ручной проверки. При отдельной настройке Search также ищет и читает публичные web-источники. Он не заменяет агента, не редактирует файлы и не исправляет проект автоматически.

## Что умеет Search

| Задача | Возможности |
| --- | --- |
| Найти код и проверить его | Лексический или настроенный поиск с embeddings, чтение актуального исходника, ограниченный контекст, путь, строки и identity snapshot. |
| Изучить структуру | Кандидаты дубликатов в релизе `v0.1.6`; текущие исходники дополнительно содержат точный поиск символов, статические references/call trace и необязательный logical context. |
| Найти другие источники | Необязательный web-поиск Brave и чтение страниц, классификация и сравнение переданных клиентом visual references. |
| Подключить существующий клиент | SDK, локальный MCP через stdio/loopback или удалённый MCP владельца через отдельно настроенный OAuth. |

По умолчанию поиск кода лексический и не вызывает модельного провайдера. Необязательные code embeddings и reranking используют специализированный профиль `voyageai/voyage-code-4` и `voyageai/rerank-2.5-lite`. Web-поиск и текстовые web-модели настраиваются отдельно. MCP предоставляет инструменты клиенту, но не задаёт ему обязательный порядок действий и не делает Search автономным.

## Установка доступного релиза

Требуется Node.js `>=20.19.0`. Сейчас доступен архив GitHub-релиза `v0.1.6`:

```sh
npm install --save-exact https://github.com/zoomplus/zorya-search/releases/download/v0.1.6/zorya-search-0.1.6.tgz
npm exec -- zorya-search setup --root .
npm exec -- zorya-search client-config
```

`client-config` печатает варианты подключения; нужный вариант надо отдельно зарегистрировать в клиенте, выдать минимальные необходимые разрешения и явно запустить индексацию командой `npm exec -- zorya-search index`. Установка сама по себе не подключает клиента и не начинает индексацию. См. [английское руководство по началу работы](docs/getting-started.en.md) или [русское руководство](docs/getting-started.md).

## Какие возможности доступны в каждой версии

В архив GitHub `v0.1.6` входят поиск и чтение исходников, сборка контекста, кандидаты дубликатов, индексация/статус и необязательные web и classification функции. В текущих исходниках дополнительно есть точные запросы символов и ссылок, ограниченная трассировка статических вызовов и `includeLogical` для `getCodeContext` / `get_code_context`. По умолчанию `includeLogical` выключен и независим от `includeRelated`; покрытие и пропуски указаны явно. Функция не обещает полноту runtime-вызовов и dynamic dispatch. Эти additions пока не входят в релизный архив `v0.1.6`.

Текущая индексация поддерживает Markdown `.md`/`.mdx` и выбранные форматы исходников и конфигурации, но не файлы правил редактора `.mdc` и не обычные `.txt`. Запрошенная отдельная функция embeddings для документации, правил и skills ещё не реализована. Подробности — в [руководстве по возможностям](docs/capabilities.md).

## Статус проекта

Исходники и пакет прошли проверки текущего основного snapshot, включая полную CI-матрицу. Это подтверждает проверенную область исходников и пакета, но не подключение hosted ChatGPT, пользовательское устройство или игру, качество на реальном провайдере либо полную приёмку программы. Доступным архивом GitHub остаётся `v0.1.6`; публикации в npm не было. Используйте Search, когда помогают индекс репозитория, привязка результата к актуальному исходнику или настроенные retrieval-инструменты. Для некоторых задач достаточно обычного поиска и чтения файлов.
